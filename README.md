# ربات خبری اقتصاد و ژئوپلیتیک (تلگرام)

هر ۱۰ دقیقه اخبار مهم اقتصادی و ژئوپلیتیک را از منابع معتبر جمع می‌کند، به فارسی ترجمه می‌کند و در کانال تلگرام می‌گذارد. کاملاً رایگان، روی GitHub Actions.

## چه چیزی پست می‌شود

- **اخبار مهم**: هر خبر امتیاز می‌گیرد (نرخ بهره، تورم، NFP، جنگ، تحریم، نفت، هرمز و…). فقط خبرهای بالای آستانه پست می‌شوند.
- **حذف تکراری**: یک خبر از چند منبع فقط یک بار پست می‌شود.
- **تقویم روزانه**: ساعت ۷ صبح تهران، فهرست دیتاهای پرتأثیر آن روز
- **یادآوری دیتا**: حدود ۴۰ دقیقه قبل از انتشار هر دیتای مهم، با عدد پیش‌بینی و قبلی
- **سخنرانی‌ها**: صحبت‌ها و مصاحبه‌های مقامات Fed، ECB، BoJ، BoE و… (🎙)
- **منبع**: نام منبع زیر هر خبر می‌آید (بدون لینک)
- **برچسب‌ها**: 🎙 سخنرانی، 🏦 بانک مرکزی، ⚔️ ژئوپلیتیک، 🛢 انرژی، 📊 دیتا، 🚫 تحریم + پرچم کشور. خبرهای خیلی مهم با 🔴 فوری

**منابع**: Fed، ECB، BoE، BoJ، Reuters و Bloomberg (از طریق Google News)، CNBC، Investing.com، FXStreet، OilPrice، BBC، Al Jazeera، Iran International، تقویم ForexFactory

## راه‌اندازی (حدود ۱۵ دقیقه)

### ۱. ساخت کانال و ربات تلگرام
1. یک کانال بسازید (برای دمو **عمومی** باشد ساده‌تر است، مثلاً `@my_econ_news_demo`).
2. به `@BotFather` پیام دهید → `/newbot` → اسم بدهید → **توکن** را کپی کنید.
3. در تنظیمات کانال → Administrators → ربات را اضافه کنید با اجازه‌ی **Post Messages**.

**Chat ID:**
- کانال عمومی: همان آیدی با @ (مثل `@my_econ_news_demo`)
- کانال خصوصی: یک پیام در کانال بفرستید، بعد این آدرس را در مرورگر باز کنید و عدد `chat.id` را بردارید (با `-100` شروع می‌شود):
  `https://api.telegram.org/bot<TOKEN>/getUpdates`

### ۲. ساخت ریپوی GitHub
1. در github.com یک ریپوی جدید بسازید. **حتماً Public** باشد.
   - ریپوی عمومی دقیقه‌ی نامحدود رایگان دارد. ریپوی خصوصی فقط ۲۰۰۰ دقیقه در ماه دارد که برای اجرای هر ۱۰ دقیقه کافی نیست.
   - توکن‌ها در Secrets ذخیره می‌شوند و در ریپوی عمومی دیده نمی‌شوند.
2. محتوای همین پوشه را در ریپو آپلود کنید (از جمله پوشه‌ی `.github`).

### ۳. اضافه کردن Secrets
در ریپو: **Settings → Secrets and variables → Actions → New repository secret**

| نام | مقدار | اجباری؟ |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | آیدی کانال | ✅ |
| `GEMINI_API_KEY` | کلید رایگان از aistudio.google.com برای ترجمه‌ی روان‌تر | اختیاری |
| `MYMEMORY_EMAIL` | یک ایمیل؛ سهمیه‌ی مترجم پشتیبان را بیشتر می‌کند | اختیاری |

### ۴. اجرا
1. تب **Actions** → در صورت نیاز روی دکمه‌ی فعال‌سازی workflowها بزنید.
2. **Telegram News Bot** → **Run workflow**
3. اجرای اول فقط پیام «✅ ربات خبری فعال شد» را می‌فرستد و اخبار فعلی را علامت می‌زند تا کانال پر از خبر قدیمی نشود.
4. از آن به بعد هر ~۱۰ دقیقه خودکار اجرا می‌شود.

## تنظیمات (`config.py`)

- `MIN_SCORE`: آستانه‌ی اهمیت. **بالاتر** یعنی خبر کمتر و مهم‌تر (پیش‌فرض ۵).
- `MAX_POSTS_PER_RUN`: حداکثر پست در هر اجرا (پیش‌فرض ۶).
- `KEYWORDS`: کلمات کلیدی و امتیاز هرکدام.
- `FEEDS`: منابع خبری. برای افزودن منبع، یک خط با لینک RSS اضافه کنید.

## ترجمه

به ترتیب امتحان می‌شود: **Gemini** (اگر کلید داشته باشید) ← **Google Translate** ← **MyMemory**.
اگر همه از دسترس خارج باشند، خبر رد نمی‌شود و اجرای بعدی دوباره تلاش می‌کند.

## محدودیت‌ها

- **تأخیر**: GitHub Actions گاهی ۵ تا ۱۵ دقیقه تأخیر دارد. برای خبر لحظه‌ای بعداً باید به سرور (VPS) منتقل شود.
- **عدد واقعی دیتا** (Actual) از تقویم رایگان در دسترس نیست. این عدد از طریق خبرهای منابع (FXStreet و Investing) چند دقیقه بعد از انتشار پست می‌شود.
- **ForexLive و BLS** ربات‌ها را مسدود می‌کنند و فعلاً در منابع نیستند.
- **X (توییتر)** طبق تصمیم فعلی استفاده نشده است.
